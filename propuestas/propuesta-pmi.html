1. Resumen ejecutivo

El Programa de Mentoría Inclusiva (PMI) conecta a aproximadamente 640 estudiantes con 200 mentores mediante reuniones de seguimiento registradas en Microsoft Forms. Hoy, el equipo PMI dedica cerca de 9 horas semanales a cruzar, corregir y consolidar esta información manualmente en Excel, lo que genera acumulación de trabajo cerca de las fechas de corte, errores de digitación y duplicados.

Esta propuesta plantea automatizar el proceso aprovechando la suite Microsoft 365 que UTP ya utiliza, sin salir de ese ecosistema ni incorporar plataformas externas, con cambio mínimo para mentores y equipo PMI.

2. Situación actual

2.1 Proceso actual

Cada mentor registra sus reuniones en Microsoft Forms: tipo de reunión, código del estudiante, mentor y evidencia (fotos o capturas de intento de contacto). El equipo PMI descarga estas respuestas periódicamente, las cruza a mano con la base maestra en Excel, corrige errores, elimina duplicados y consolida la información antes de generar reportes en Power BI y enviar recordatorios por Outlook.

4. Cómo se automatiza

La automatización se construye con Power Automate, integrando Forms, SharePoint, Excel, Outlook y Power BI, sin reemplazar ninguna herramienta que UTP ya usa. La solución permanece 100% dentro del ecosistema Microsoft 365 de UTP — no se incorpora ninguna plataforma o servicio externo.

  • Menor inversión, implementación más rápida
  • Cambio mínimo para los usuarios
  • Aprovecha licencias que UTP ya tiene

5. Alcance y entregables

  • Validación de código de estudiante y mentor asignado
  • Control de duplicados y secuencia entre reuniones
  • Contexto y seguimiento de acuerdos entre reuniones
  • Consolidación automática para Power BI

6. Requisitos y supuestos

Todo lo necesario para construir y operar la automatización vive dentro de Microsoft 365 — no se requiere ninguna herramienta ni plataforma externa a UTP.

6.1 Acceso necesario

Se requerirá una cuenta dentro del tenant de Microsoft 365 de UTP para el equipo de desarrollo, con permisos para crear y publicar flujos en Power Automate, y para acceder a Microsoft Forms, SharePoint, Excel, Outlook y Power BI del PMI. La forma de otorgarla (usuario interno, invitado u otra) queda a criterio de UTP; basta con que el acceso quede solicitado de forma explícita antes de iniciar el desarrollo.

6.2 Licencias

Power Automate ya suele estar incluido en la mayoría de planes de Microsoft 365. Queda pendiente validar con TI de UTP si el plan contratado alcanza para el volumen del PMI (≈640 estudiantes por ciclo) o si se requiere licencia adicional por usuario o por flujo. Power Apps no es necesario para este alcance — no se contempla una aplicación o interfaz nueva.

6.3 Supuestos

  • Acceso oportuno a Forms, SharePoint, Power Automate y Power BI de UTP, y a los datos reales cuando corresponda
  • Base maestra de estudiantes y mentores actualizada y disponible
  • La inversión de implementación no incluye las licencias o suscripciones de Microsoft 365, que UTP administra directamente
  • Cambios de alcance solicitados durante el proyecto se cotizan por separado
